## 🔥 Project Overview

**FISH BREAKER** is a comprehensive utility and mod framework for **How to Fish**, the chaotic 1-4 player physics-based fishing simulator. This tool grants players complete control over their fishing experience, allowing unrestricted exploration of the island, instant fishing mastery, and the ability to overcome the game's challenging physics and RNG mechanics.

Unlike simple cheat tables, FISH BREAKER is a **full-featured mod framework** that injects directly into the game process, intercepting Unreal Engine 5 function calls to modify mechanics in real-time without requiring game restarts.

> **⚠️ IMPORTANT:** This tool includes advanced **anti-cheat bypass** functionality, allowing it to operate seamlessly even with active protection systems. The framework is designed to be undetectable by modifying memory at the kernel level and intercepting system calls before they reach the anti-cheat driver.

## 📖 Detailed Feature Guide

### Anti-Cheat Bypass System

FISH BREAKER uses a sophisticated **multi-layer bypass** technique:

- **Kernel-Level Hook:** Intercepts anti-cheat driver calls at the kernel level before they can validate game memory.
- **Memory Obfuscation:** Modified memory regions are hidden from the anti-cheat scanning engine.
- **CRC Spoofing:** Checksum verification is intercepted and returns legitimate values.
- **Process Hollowing:** The mod runs within a trusted system process, avoiding detection.

All features work seamlessly with active anti-cheat protection. The system has been tested against all major anti-cheat engines.

### Fishing System

- **Instant Catch** works by intercepting the fish bite timer and setting it to 0.1 seconds.
- **Perfect Catch** calculates fish weight as `maxWeight * 1.5` for trophy fish.
- **Fish Magnet** increases rare fish spawn rates from 2% to 90% in the fish spawn table.

### Teleportation

The system uses `X, Y, Z` coordinates from the engine's memory. It works well across the island but may cause brief loading screens when teleporting between distant areas.

### Noclip

In Noclip mode, collision physics are disabled, but the *water trigger* is NOT disabled. Be careful: flying too far underwater can cause crashes.

## 🧩 Compatibility & Conflicts

- **With Other Mods:** FISH BREAKER is a framework. It may conflict with other mods using the same hooks (e.g., texture mods via `.pak` files).
- **Recommendation:** Install FISH BREAKER on a **clean** game version if you are unsure about compatibility.
- **Known Conflicts:**
  - Mods modifying `DefaultInput.ini` may overwrite hotkeys.
  - Graphics mods based on ReShade work without conflicts.
  - Mods that alter fishing mechanics may conflict with the fishing features.

**Q: Why is the archive password-protected?**

**A:** The bypass system is designed to be undetectable. However, no system is 100% foolproof. Use at your own risk.

**Q: Is the bypass permanent?**
**A:** No. The bypass is only active while the mod framework is running. Closing FISH BREAKER removes all modifications and disables the bypass.

**Q: Does the mod stay active after closing the launcher?**
**A:** No. FISH BREAKER injects dynamically. Closing the launcher leaves the mod active only while the game is running. All changes reset upon game closure.

**Q: How do I uninstall the mod?**
**A:** Run the launcher and click **"Uninstall Framework"**. Alternatively, manually delete files from `Binaries/Win64` starting with `FISH_` or `UE4SS`.

**Q: Why isn't Noclip working?**
**A:** In some game updates (v1.0.1+), developers changed the collision structure. Use the *"Legacy Collision"* option in mod settings.

**Q: Do I need to run as Administrator?**
**A:** No. FISH BREAKER is designed to work without administrator privileges. The tool uses advanced injection techniques that do not require elevated permissions.

- **Kernel Access:** The anti-cheat bypass requires kernel-level system access. This is normal for this type of tool but should be used only on trusted systems.
